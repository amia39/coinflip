# coinflip

Discord bot that simulates a variety of probability experiments.

Developed in Python 3 with Pycord.

## Commands

Coins:

>`/flip`  Returns the result of a single coinflip.
>`/flipmore`  Returns the result of multiple coinflips, up to 99999 at once.
